# VTZ - Valenzuela Tricycle Zone

## About

VTZ (Valenzuela Tricycle Zone) is an Android application designed to help commuters in Valenzuela City
discover tricycle terminals and access useful terminal and commuter information.

Finding the right tricycle terminal should not be confusing. VTZ brings terminal information and
commuter-focused services into one accessible platform designed for Valenzuela City.

## Features

- Terminal Discovery — find and explore tricycle terminals in Valenzuela City.
- Terminal Information — access useful information about tricycle terminals.
- Routes — explore relevant terminal route information supported by the application.
- Fare Information — view relevant fare information supported by the application.
- Lost Item — report a lost item and access relevant lost-item information.
- Complaint Reporting — submit commuter-related concerns through the application's reporting feature.

## Purpose

VTZ exists to make everyday commuting easier for Valenzuela City commuters by bringing tricycle terminal
discovery, terminal details, route and fare context, and supporting commuter services into a single mobile
experience.

## Scope

VTZ is a commuter-focused tricycle terminal discovery and information application for Valenzuela City.

VTZ is not a ride-hailing, booking, reservation, driver-tracking, or payment application.
